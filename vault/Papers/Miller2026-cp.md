# Community-driven API and AI writer design for openly scaling Community Notes

> Miller, B., Baxter, J., Chao, J., Coleman, K., Hilgard, S., & Ortiz, D. (2026). Community-driven API and AI writer design for openly scaling Community Notes. *arXiv [cs.SI]*.
>
> [View paper](http://arxiv.org/abs/2609.40067v1)

## Summary

This paper describes the design of an open API and AI writer system for scaling X's Community Notes, the platform's crowd-sourced fact-checking and context-adding system. Launched in September 2025, the AI Note Writer API provides a public interface that lets AI systems propose notes while preserving the system's founding principle: human users—not the platform or the AI—decide which notes become broadly visible. The authors argue that AI can expand note production at scale without ceding control over display decisions, provided that community contribution and rating remain the arbiters of visibility and that the open-source, open-data ranking algorithm stays intact.

## Key Contributions

- An open, public API design that lets AI systems participate in Community Notes while retaining human control over which notes are shown.
- A framework for scaling crowd-sourced contextual annotation by combining AI note generation with community rating and ranking.
- Preservation of open-source and open-data principles within an AI-augmented content-moderation/context system.

## Methods

- Design and deployment of the AI Note Writer API as an open, public interface (launched September 2025).
- Integration of AI-proposed notes into the existing open-source, open-data Community Notes rating and ranking algorithm, so AI-generated notes compete on the same terms as human ones.
- Use of explicit note requests and user posts as inputs/triggers for note generation (specifics truncated in the available abstract).
