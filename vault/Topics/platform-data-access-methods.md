# Platform Data Access & Research Methods

Methodological and infrastructural work on how researchers access, use, and are constrained by social media platform APIs and datasets (CrowdTangle shutdown, Meta URL Shares Dataset thresholds, DSA-era APIs, clean-room environments), a recurring concern for reproducible computational social science.
